# v2 before / after

Production baseline was inspected directly. Some production script versions predate the supplied local source; before images are labelled production, after images are the local v2, not a claim of deployment.

| Surface | Original problem | New behavior and reason | Evidence |
|---|---|---|---|
| Home | Cinematic controls and several entry paths compete | Scene-led invitation with mission, practice and a short first-flight route | [Before](screenshots/before/production-home-1440.png) · [After](screenshots/after/home-1440.png) |
| Mission select | Selection primarily looks like a menu | Two visual rescue scenarios explain objective and learning concepts | [Before](screenshots/before/production-missions-1440.png) · [After](screenshots/after/missions-1440.png) |
| Briefing | Full bilingual manual before programming | Short goal/constraints with optional detailed rules | [Before](screenshots/before/production-briefing-1024.png) · [After](screenshots/after/briefing-1440.png) |
| Simulator | World competes with controls, HUD and logs | Largest region is the world; three workspace modes; compact contextual HUD; logs collapsed | [Before](screenshots/before/production-simulator-1280.png) · [After](screenshots/after/simulator-1440.png) |
| Blockly | Hidden on entry, blank workspace, English blocks | Immediately available, a starter action, Chinese labels, undo/redo, command feedback | [Before](screenshots/before/production-blockly-1440.png) · [After](screenshots/after/free-practice-1440.png) |
| Results | Completion reports scores without a clear next task | Score breakdown retained; retry preserves program; next mission is primary; optional goals guide improvement | [Before](screenshots/before/production-result-1024.png) · [After](screenshots/after/result-1440.png) |

| Phone portrait | Crowded simulator | Explicit rotate prompt and optional continuation | [Before](screenshots/before/production-portrait-390.png) · [After](screenshots/after/portrait-390.png) |

The redesign changes information architecture and mode behavior, not only styling. It keeps the existing simulation foundation, assets, score thresholds and XML format. Camera framing, lighter practice ground, clearer forest lighting/fog and projected drone/landing labels improve observation without changing physics.
