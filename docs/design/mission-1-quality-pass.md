# Mission 1 Scene Quality Pass

2026-09-24。使用者已審閱 audit 並批准 Preserve + Polish；Subagents：無。

## 保留的任務契約

Mission 1 是震後街區路網，從 Alpha 送情報至 Bravo 並降落，三巡檢為選做。沒有建立 v2 或平行場景。

- 地圖 12×12，每格 150cm，offset (-900,-900)；84 阻擋格與 60 可通行格。
- Alpha (-675,0,-675)，heading 180；Bravo (825,675)，以下平面座標均為 (x,z)。
- 巡檢座標 (75,-675)、(675,-75)、(-675,525)。水平距離 <70、高度與 50 相差 <45；巡檢時間 3 秒。
- 路網記錄只接受 y≤150；已走過的道路格需連通起終點。
- 已起飛計時、位於 Bravo 格、isFlying=false、y≤120 才可完成。
- 建築格所有高度都阻擋，原有 15cm 採樣半徑、回退行為、320cm 飛行上限、goto_xyz 禁用維持。
- 完成200、每巡檢100；60/90/120/180秒內時間獎500/350/200/80；超時不判負。
- 物理、Blockly、mission_rules、移動、感測器計算、完成和失敗行為均未修改。

## Audit 與決策

原場景已有 Kenney 建築、屋頂、窗戶、道路、樹群、噴水池、36個外圍位置與四組路障。並非缺乏素材；問題是純色基底、偏白配色、外圍孤立、過強填光與弱任務據點。

| 分類 | 決策 |
|---|---|
| KEEP | 城市身份、全路網與座標、道路方向、建築和樹群的形狀位置、無人機與相機操作 |
| POLISH | 地面色差、地塊色彩空間、日光方向、陰影覆蓋、地面與樓宇對比、外圍鋪面連續性 |
| REPLACE | 浮動箭嘴和發光球體的可見外觀，以地面H標、站牌、小型巡檢設備呈現 |
| REMOVE | 舊標示的可見繪製與其局部光照；不移除感測形狀 |
| ADD | Alpha通訊補給、Bravo接應棚、周邊花槽、兩處封鎖維修線索、完成勾號 |
| REVIEW REQUIRED | 任務條件、格線、感測形狀、建築輪廓、位置、玩法與Mission 2；本次不改 |

## 實作與限制

`createMazeMap` 在原 builder 完成後呼叫 `polishMission1Environment`。一個 Mission 1 視覺 pass，沒有第二套地圖。建築改善來自材質／地基對比與光影，保留其現成屋頂、窗戶、比例和輪廓；不加入會改變傳感結果的建築細節。

- 色彩：低飽和草地、暖灰鋪面、深色設備、救災橙；Alpha藍綠、Bravo綠，文字和H標輔助識別。
- 光影：主光從側上方塑造體積；半球光降低；保留無人機自己的細節光。主陰影2048不升級，縮窄覆蓋至3100×3100。道路仍不接收即時陰影，避免重引入原有黑線。
- 地面：原 footprint、原高度；頂點色細微變化。外圍鋪面及花槽連接既有外圍建築，不另建道路或森林。
- 任務據點：標線覆蓋原起終點中心；淨空仍由原碰撞契約定義。小型裝飾置於邊緣，非交互、非感測對象。
- 巡檢：保留 beaconData 與原來的完成／重置更新；新勾號只讀 triggered，不改變評分。原巡檢球體/箭嘴隱藏但保留原射線幾何和動畫變換。
- 重要發現：舊傳感器在「是否有任何射線交點」後才過濾 isWall。新裝飾即使沒 isWall 也可能改變結果。因此裝飾明確不參與 raycast，舊隱藏標記仍可被射線檢測；最終 2880 讀值完全一致。
- 生命周期：離開 Mission 1，精確還原借用燈光的顏色、亮度、位置、半球地色及陰影相機。Mission 2 files/assets 不變。
- 效能：同色道具使用InstancedMesh；相同地塊／地基材質共享。新增四張256px程式貼圖，沒有下載，沒有大紋理，沒有新增投影光。

視覺檢視分初次整體檢查與修正確認。首輪發現外圍鋪面深度閃爍，增加裝飾表面高度間距後確認消除；未改變可玩地面的 getGroundHeight。
