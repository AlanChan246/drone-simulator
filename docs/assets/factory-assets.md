# Mission 3 工廠素材

所有新增GLB來自Kenney官方CC0素材包，作者Kenney。模型原始位元組未改動；只在Three.js場景中調整比例、位置、方向，clone場景材質、共用幾何並批次繪製。授權檔隨模型保留。遊戲使用專案內資源，沒有熱連外部模型。

| 素材包 | 官方來源 | 使用位置 |
|---|---|---|
| Factory Kit 3.0 | https://kenney.nl/assets/factory-kit | 輸送帶、取件掃描器、維修和裝配機、機械臂、管道、工具／箱件、磁力夾具與零件 |
| City Kit Industrial 2.0 | https://kenney.nl/assets/city-kit-industrial | 倉庫、外圍廠房、儲罐、貨櫃、太陽能板、風機及水塔 |
| Space Kit（隨包License標示2.0） | https://kenney.nl/assets/space-kit | 救援能源核心、運輸載具、基地車輛、能源裝置、圍欄及桶件 |

下載來源、每個檔案的路徑／大小／SHA-256／授權／修改紀錄：`audit/factory/assets-manifest.json`。Factory Kit、Industrial及Space三個子目錄均保留原始 `License.txt`；GLB外部材質貼圖一併存放。沒有假設素材包含機甲；最終救援設備由已有能源機器模型組合呈現。

50個GLB合計1,974,140 bytes（約1.88MiB）；確切模型加貼圖總量與瀏覽器實測見測試報告。地面、標線、操作範圍及文字提示使用簡單幾何／Canvas貼圖；主要可見建築、機器、輸送帶和道具全為外部模型。無人機沿用現有模型。

場景預覽圖 `assets/images/mission-preview-factory.png` 是本模擬器完成場景的瀏覽器截圖。沒有AI生成或概念圖充當實機畫面。
